## ⚓ Overview

Athen Marine is a high-performance marine lubricants brand engineered for modern ocean-going merchant fleets, container carriers, bulkers, tankers, and offshore support vessels. In strategic collaboration with Legero International Group B.V., Athen Marine combines European blending standards, OEM engine approvals, and global port bunkering logistics.

### Key Sections Covered:
- **Hero & Core Credentials**: "Intellectual Engineering Delivering Trust", key operating metrics, and Legero strategic partnership backing.
- **About Us & Value Proposition**: Our Story (2020 to 5,000+ vessels in 5 years), 24/7 trusted team, technical excellence, and reliable supply.
- **Vision & Mission**: Global brand vision, 3 key delivery pillars, and core values (Agility, Growth, Trust, Partnership).
- **Athen Creating Waves (Expansion Highlights)**: Blending in Greece (EU ports), dedicated Rotterdam ARA Barge delivery, Blending in India, and Legero International Group synergy.
- **Product Portfolio**: Full product catalog with technical specifications and OEM compatibility across:
  - *Main Grades* (Cylinder Oils & System Oils for two-stroke & four-stroke engines)
  - *Secondary Grades* (Marine Hydraulics EP, Reduction Gear Oils, Compressor Fluids)
  - *EAL Bio-Lubricants* (US EPA VGP 2013 compliant stern tube and deck machinery oils)
  - *Marine Greases* (Lithium complex EP 2 & OpenGear / WireRope compounds)
- **Global Reach & Port Network**: Interactive port directory across Europe/ARA, Middle East/Arab Gulf, Asia-Pacific, Indian Subcontinent, and Americas.
- **Evolution Roadmap**: Journey timeline from 2020 through 2030 (Target: 10% of Global Fleet powered by Athen).
- **Leadership & Board Members**: Highlighting Gerrie Plune & Robert Plune, Jack Craig, Santosh Menon (CEO), Girlie Ventura, Sathya Prasad, and Liji Suresh.
- **24/7 Port RFQ & Contact Desk**: Interactive vessel inquiry form for spot quotations and port delivery scheduling.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build

# 4. Preview build
npm run preview
```

---

## ☁️ Deployment to Vercel

This repository is pre-configured with `vercel.json` for seamless 1-click deployment:

1. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
2. Import `akasshmanikandan/athen_marine_lubricants`.
3. Framework Preset: **Vite** (automatically detected).
4. Click **Deploy**.

Alternatively via Vercel CLI:
```bash
npx vercel --prod
```
